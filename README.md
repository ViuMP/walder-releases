# Walder — downloads

Walder is a small pixel-art dachshund who sits on your desktop and keeps an eye on how much of your
Claude and ChatGPT allowances you have left. This repository holds **only the installers**; the source
code is private.

## Install

Go to **[Releases](https://github.com/ViuMP/walder-releases/releases)** and download the newest file for
your machine:

| You have | Download | First launch |
|---|---|---|
| Mac (Apple silicon) | `Walder-<version>-mac-arm64.dmg` | macOS will block it: **System Settings ▸ Privacy & Security ▸ Open Anyway**, once. |
| Windows | `Walder-<version>-win-x64.exe` | SmartScreen will warn: **More info ▸ Run anyway**. Untested by the developers — please report what you see. |

Walder is not signed with a developer certificate, which is why both systems warn. The full guide
(logging in, what his faces and barks mean, troubleshooting) ships inside each release as `HANDBOOK.html`.

## Updating

Walder checks this repository about every six hours and tells you when a newer version exists; the menu
then links back here. Nothing is downloaded or installed on its own — you install the new file over the
old one exactly as above.
